A useful second life

One old phone. One visible signal that your car is not being ignored.

Place a spare phone securely inside the car, point its rear light where it can be seen, and start the Security Light. The feature runs independently of the paid monitoring tools in BlackShisa - Parking Dashcam App.

Set it in minutes

Choose the signal. Protect the battery. Start blinking.

The controls are deliberately simple, so a phone you already own can become a visible car security light without extra hardware or wiring.

1

Open the free Security Light.

Use it directly from the subscription screen or the app settings. A paid plan is not required.

2

Tune the blink pattern.

Adjust how long the light stays on, how long it stays off, and—on supported devices—its brightness.

3

Set safeguards and run it.

Choose a battery stop level and maximum duration, optionally ignore the battery limit while charging, then dim the screen.

No paywall for the light

Use Security Light for free. Upgrade when you need evidence recording.

Security Light is free inside BlackShisa - Parking Dashcam App. The $6.99/month subscription unlocks motion, sound, and impact monitoring, pre-event video evidence, Google Drive backup, and Gmail alerts.

  • Free: blinking light, timing controls, battery protection, and screen dimming
  • Subscription: detection, evidence recording, backup, and alerts
  • Your choice: continue with the free light or start the 7-day trial

Use it thoughtfully

A visible deterrent, not a guarantee.

The Security Light is designed to help discourage unwanted attention. Its visibility depends on the phone, placement, glass, ambient light, and surroundings. Secure the phone so it cannot interfere with driving, avoid directing the light at drivers, and follow local rules.
